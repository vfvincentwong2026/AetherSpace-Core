## 🌌 核心定位 · Overview

**AetherSpace-Core** 是一个面向未来建筑、室内与商业空间设计的 **AI Native 空间智造底层引擎（Headless Spatial Intelligence Middleware）**。

它打破了传统设计与落地的数据壁垒，将顶级建筑媒体（如 ArchDaily、gooood、Pinterest）的结构化素材库、新材料与工艺知识图谱、**MCP（Model Context Protocol）标准服务协议**以及 **A2A（Agent-to-Agent）多智能体蜂群网络**深度融合。

它既可以作为独立的 SaaS 引擎与开发者工具库，也可以无缝作为垂直业务（如高端别墅全案服务平台 *Nusantara Atelier*）的核心大脑与算量后盾。

---

## 🛠️ 核心架构能力 · Core Capabilities

1. **多源专业数据与知识图谱（Data & Taxonomy Pipeline）**
   - 结构化管理多维空间分类（商业、住宅、公共空间）。
   - 融合空间白模、新材料 SKU、施工工艺及真实单方造价矩阵。

2. **MCP 标准服务协议（Model Context Protocol Servers）**
   - 将空间检索、印尼及全球材料 SKU、算量规则封装为标准化 MCP Servers。
   - 允许任何兼容 MCP 的大模型客户端与 Agent 直接安全调用空间数据与工程资产。

3. **A2A 多智能体协同网络（Agent-to-Agent Swarm）**
   - 汇聚主理建筑师 Agent、美学风格 Agent、材料工艺 Agent、造价与 BOM Agent。
   - 实现“概念设计 → 材料校验 → 超预算自动协商 → BOM 精准算量”的闭环自动化工作流。

4. **所见即所得的渲染与算量联动（Rendering & BOM Engine）**
   - 支持参数化空间模型搭配，实现材质实时替换与成本动态联动。
